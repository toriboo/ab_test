# A/B-тестирование: анализ влияния нового дизайна на CTR

**Цель проекта:** провести A/B-тест и определить, влияет ли изменение в экспериментальной группе (новый дизайн) на вероятность клика пользователя (CTR).

---

## 📁 Данные

- **Источник:** [A/B Testing Data (Kaggle)](https://www.kaggle.com/datasets/sanxhi/ab-testing-data-simulated-web-user-engagement)
- **Файл:** `ab_test_dataset.csv` (~200 000 записей)
- **Тип данных:** синтетические, имитируют поведение пользователей на сайте

---

## 🔍 Этапы анализа

1. **Загрузка и первичный осмотр** (`head()`, `info()`, `describe()`)
2. **Обработка пропусков** (`group`, `click_time`, `referral_source`)
3. **Приведение категориальных признаков к единому формату** (регистр, пробелы, дублирующиеся значения)
4. **Формулировка гипотез** (H₀, H₁)
5. **A/A-тест** для проверки валидности инструмента
6. **A/B-тест** (Z-тест для пропорций)
7. **Интерпретация результатов и выводы**

---

## 📊 Ключевые выводы

- **CTR в контрольной группе:** 20.4%
- **CTR в экспериментальной группе:** 49.6%
- **Разница:** +29.2% (статистически значима)
- **p-value:** ≈ 0 (нулевая гипотеза отвергается)
- **A/A-тест:** p-value = 0.8937 (инструмент корректен)

**Вывод:** изменение в экспериментальной группе статистически значимо повышает CTR. Рекомендуется внедрять.
